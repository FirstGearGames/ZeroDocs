# Welcome to V2

This is version 2 of the documentation site. This version includes new features and improvements over v1.

## What's New in V2

### Performance Improvements

- Faster build times
- Optimized search index
- Improved caching strategies
- Better mobile performance

### New Features

- Enhanced search with better ranking
- Improved dark mode
- New component library
- Better accessibility
- More customization options

### Breaking Changes

- Requires Node.js 18+
- Some configuration options renamed
- Component API changes

## Migration from V1

If you're coming from V1, check the migration guide in the v1 documentation.

## What's the Same

- Markdown-based content
- File-system routing
- Search functionality
- Theme toggle
- Mobile support

## Getting Started with V2

1. Update your Node.js version to 18+
2. Install dependencies: `npm install`
3. Update `docs.config.json` if needed
4. Start dev server: `npm run dev`

## Documentation Structure

V2 keeps the same documentation structure as V1, so your existing content will work with minimal changes.

The documentation is organized into:

- **Getting Started**, Setup and basics
- **Guides**, How-to guides
- **Manuals**, Reference documentation

For questions about V2:
