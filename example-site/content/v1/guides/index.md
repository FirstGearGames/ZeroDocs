# Guides

Welcome to the Guides section. Here you'll find step-by-step guides for common tasks and workflows.

## Available Guides

### 1. Adding Content

Learn how to create new documentation pages and organize them using the folder structure.

Topics covered:
- Creating Markdown files
- Using frontmatter
- Organizing content in folders
- Using `_meta.json` for navigation control

### 2. Customization

Customize the appearance and behavior of your documentation site.

Topics covered:
- Changing colors and themes
- Adding your logo
- Modifying fonts
- Customizing navigation
- Adding custom components

## Guide Format

Each guide is designed to be:

- **Practical**, Focused on how to do something
- **Step-by-step**, Easy to follow instructions
- **Example-driven**, Real-world examples
- **Short**, Focused on one topic at a time
